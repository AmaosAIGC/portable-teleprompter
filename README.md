# 便携式提词器与脚本同步系统（毕设版）

> Portable Teleprompter & Script Sync System — 武汉传媒学院 电子信息工程 毕业设计
> 题目：便携式提词器与脚本同步系统 ｜ 指导教师：李文 ｜ 状态：开发中

基于 **ESP32-WROOM-32E** 的低成本便携提词器：2.8 寸 TFT 显示、编码器调速与平滑滚动、BLE 手机 App 控制、蓝牙遥控、TF 卡脚本管理，配合 45° 分光镜结构，面向学生剧组拍摄与短视频口播场景。

## 选题内容

**原材料**：STM32/ESP32 主控、TFT/LCD 显示屏、蓝牙模块、无线遥控、手机 App、SD 卡，开发语言 C/C++。

**模块 1 · 提词显示**：采用 TFT/LCD 显示屏显示脚本文字，支持字体大小、行距、颜色调节；屏幕可适配提词器结构。

**模块 2 · 滚动速度调节**：通过按键或旋钮调节脚本滚动速度，支持暂停/继续；速度平滑可调。

**模块 3 · 手机/遥控翻页**：通过蓝牙连接手机 App 或无线遥控器，实现翻页、跳转、暂停控制；支持脚本导入与编辑。

**模块 4 · 脚本管理**：支持 TXT 脚本导入，保存多份脚本，手机端可预览与修改。

**应用价值**：解决学生剧组拍摄提词靠手举、效率低的问题，提供低成本便携提词方案。

## 为什么做这个

市售手机提词器（¥11–60）必须依赖手机和 App，断网、手机没电就失效。本方案：

- **离线可用**：TF 卡直读 TXT，不依赖手机
- **成本可控**：整机 BOM 约 ¥200
- **显示可调**：字号 / 行距 / 颜色 / 镜像现场可调
- **双通道控制**：BLE 手机 App + 蓝牙遥控互为备份

## 功能模块

| 模块 | 内容 | 关键指标 |
|---|---|---|
| 提词显示 | 2.8" TFT 240×320，ST7789，GB2312 汉字 16/24 点阵 | 整屏刷新 ≤200ms |
| 结构适配 | 45°±5° 分光镜 + 遮光罩 + 水平镜像 | 40~60cm 可读 |
| 滚动调速 | EC11 编码器，10~300 px/s | 误差 ≤5%，可分档 |
| 手机控制 | BLE + 自研 Android App | ≥10m，响应 ≤300ms |
| 无线遥控 | 蓝牙遥控器 | 与手机端互为备份 |
| 脚本管理 | TXT（UTF-8/GBK），多脚本，手机端读回修改 | ≥100KB，≥10 份，切换 ≤2s |

## 硬件

ESP32-WROOM-32E 一体带屏板（2.8" ST7789 + TF 卡座 + XPT2046 触摸）、EC11 编码器、nRF24L01 / 蓝牙遥控器、2500mAh 锂电池底座、亚克力分光镜。

引脚分配与接线见 [`docs/03-系统架构与固件设计.md`](docs/03-系统架构与固件设计.md)。
