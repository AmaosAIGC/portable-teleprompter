# 便携式提词器与脚本同步系统

> 🚧 **项目进行中** — 本文件随开发实时更新，预计 **2 个月内**完成作品。

> Portable Teleprompter & Script Sync System
> 状态：开发中

基于 **STM32F401CCU6** 的低成本便携提词器：2.8 寸 TFT 显示、EC11 编码器调速与平滑滚动、HC-05 蓝牙手机控制、W25Q64 存字库与多脚本，配合 45° 分光镜结构，面向学生剧组拍摄与短视频口播场景。

## 选题内容

**原材料**：STM32、TFT/LCD 显示屏、蓝牙模块、无线遥控、手机端、SD 卡（拓展）、C/C++。

**模块 1 · 提词显示**：TFT 显示屏显示脚本文字，支持字体大小（两档点阵，软件预留）、行距（两档）调节；屏幕可适配提词器结构。

**模块 2 · 滚动速度调节**：通过编码器调节滚动速度，支持暂停/继续，速度平滑可调。

**模块 3 · 手机/本地控制**：HC-05 蓝牙与手机串口助手通信，实现翻页、跳转、暂停；EC11 + 按键作为本地备用控制。

**模块 4 · 脚本管理**：脚本经蓝牙下发，设备保存多份，掉电不丢失。

**应用价值**：解决学生剧组拍摄提词靠手举、效率低的问题，提供低成本便携提词方案。

## 硬件方案

| 部件 | 型号 | 作用 |
|---|---|---|
| 主控 | STM32F401CCU6 核心板（Black Pill） | 84MHz Cortex-M4F，256KB Flash / 64KB SRAM，SPI 42MHz |
| 显示 | 2.8" TFT 240×320，ST7789，SPI | 提词文字显示，支持硬件垂直滚动与镜像 |
| 存储 | W25Q64（8MB SPI Flash） | GB2312 点阵字库 + 多份脚本 + 参数 |
| 无线 | HC-05 蓝牙串口模块 | 手机串口助手下发脚本与控制指令 |
| 交互 | EC11 旋转编码器 + 独立按键 | 调速、暂停、一级菜单 |
| 光学 | 45°±5° 分光镜 + 遮光罩 | 同轴视线提词，镜像正读 |
| 电源 | Type-C 5V + 3.7V/2500mAh 保护板电池 | 便携供电 |
