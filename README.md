# 便携式提词器与脚本同步系统

武汉传媒学院电子信息工程毕业设计（项目制小组选题）个人分支工程。

- **我做**：便携提词器硬件 + 固件 + 脚本管理 + 手机/遥控翻页
- **不做**：项目卡其他分支（与组员共用手机端与协议）
- **服务对象**：学生剧组拍摄提词、短视频口播
- **交付物**：提词器实物 + 脚本管理程序 + 手机/遥控翻页功能 + 毕业论文

## 快速开始
1. 先看 `STATUS.md` 了解当前进度
2. 要动手前看 `docs/01-需求与验收标准.md` 和 `docs/03-系统架构与固件设计.md`
3. 采购看 `docs/02-硬件选型与BOM.md`
4. 与组员对接协议看 `docs/04-BLE与遥控通信协议.md`

## 差异化（答辩必答）
对比市售手机提词器（¥11–60，必须依赖手机 + App）：
1. **不依赖手机**：SD 卡直读 TXT，断网断蓝牙照样滚动
2. **成本低**：整机 BOM ¥200 以内
3. **显示可定制**：字号/行距/颜色/速度曲线
4. **本地化**：无 App 推送、无隐私与网络依赖
