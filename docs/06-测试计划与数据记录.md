## 测试项与指标

### T1 滚动速度精度
| 设定速度 | 理论时间（滚动一屏 240px） | 实测时间 | 误差 |
|---|---|---|---|
| 20 px/s | | | |
| 60 px/s | | | |
| 120 px/s | | | |
| 240 px/s | | | |
要求：误差 ≤5%，且视觉无跳行。

### T2 翻页响应延迟
| 通道 | 次数 | 最小 | 平均 | 最大 |
|---|---|---|---|---|
| BLE | 20 | | | |
| 2.4G | 20 | | | |
要求：BLE ≤150ms，2.4G ≤100ms

### T3 脚本加载/导入
| 文件大小 | 编码 | 载入耗时 | 是否乱码 |
|---|---|---|---|
| 1KB | UTF-8 | | |
| 10KB | UTF-8 | | |
| 10KB | GBK | | |
| 100KB | UTF-8 | | |
要求：乱码 0，10KB ≤1s

### T4 多脚本管理
- 存 10 份脚本，切换耗时、列表刷新耗时、掉电重启后完整性

### T5 通信可靠性
- BLE 连续 200 条命令丢包率；2.4G 5m/隔墙 各 200 条丢包率
要求：BLE 丢包 0，2.4G 室内 5m 丢包 ≤1%

### T6 稳定性
- 连续运行 2 小时，记录：重启次数、卡顿次数、内存余量曲线（串口打印 free heap / PSRAM free）

### T7 显示可读性
- 字号 16/24/32 × 三种颜色 × 装分光镜前后，主观评分（1–5）+ 拍照存档
- 亮度用手机照度计 App 读屏面 lux（可作为数据）

### T8 功耗（若用电池）
- 待机/滚动 两种状态电流，估算续航
