# 答辩问题库

> 🚧 **项目进行中** — 本文件随开发实时更新，预计 **2 个月内**完成作品。

按被问概率排序，答案控制在 30 秒内。

1. **和淘宝几十块的手机提词器有什么区别？**
   不占用手机、不依赖 App、断网可用；本地存 3 份以上脚本；成本 ¥200 以内；可现场调速与切换。
2. **为什么选 STM32F401 而不是更便宜的 F103？**
   F103 的 SPI 数据手册上限 18MHz，达不到任务书的 40MHz；F401 的 SPI1 是 42MHz，合规且只贵 ¥13。另外 256KB Flash / 64KB SRAM 让缓冲更宽裕。
3. **为什么不用 SD 卡存脚本，反而用 W25Q64？**
   SD 卡要 FATFS 与更长初始化，W25Q64 直接按扇区读写、上电即用、抗振动；任务是原型，可靠性优先。SD 卡字库更新列入展望。
4. **SPI 42MHz 够不够？**
   整屏 150KB ÷ 5.25MB/s ≈ 28.6ms；滚动用屏内硬件滚动只改寄存器，几乎不占带宽，余量很大。
5. **64KB RAM 怎么放得下一屏文字？**
   不放整屏。用行条带缓冲 + ST7789 的 VSCRDEF/VSCRSADD 硬件滚动，GRAM 存在屏里。
6. **镜像为什么不用软件翻转？**
   MADCTL 的 MX 位硬件翻转，零 CPU 开销；软件逐像素翻要重算 76800 个点，慢十倍。
7. **中文字库怎么存、怎么寻址？**
   GB2312 16/24 点阵烧在 W25Q64 字库区；区位码公式 (区-1)×94+(位-1) 乘单字字节数得偏移，一次读一两个字。
8. **UTF-8 文本怎么显示？**
   先探测编码（BOM/字节特征），UTF-8 转 GB 内码再查表；生僻字显示占位符，保证不崩。
9. **滚动为什么平滑？**
   定时器给时基，按 px/s 累积步进，配合硬件滚动只更新起始行；页切换用重叠区遮住跳变。
10. **蓝牙丢包怎么办？**
    帧头 AA55 + 长度 + CRC8 校验，错帧丢弃；脚本分包带序号与整包 CRC32，失败重传。
11. **为什么用 HC-05 不用 BLE？**
    任务书指定；HC-05 是 SPP，安卓串口助手直接可用，无需开发 App，节省一个月。代价是 iOS 不支持、功耗略高。
12. **HC-05 和调试串口冲突怎么办？**
    调试走 SWD，USART1 专供蓝牙。
13. **掉电脚本为什么不会丢？**
    写 W25Q64 前先擦扇区、带长度与 CRC 头、参数双区轮换；上电校验失败自动回退。
14. **一秒内能切换脚本吗？**
    脚本 100KB，SPI 读约 0.4s，加索引重建 <1s，指标 2s 有裕量。
15. **续航多少？怎么算？**
    2500mAh、平均约 150mA、升压与 LDO 效率约 58%，理论 8 小时以上，指标写 ≥1 小时是保守值。
16. **创新点在哪？**
    低成本独立提词 + 屏内硬件滚动零 RAM 占用 + 分光镜配 MADCTL 硬件镜像 + 双通道（蓝牙/本地）控制。
17. **测过什么数据？**
    引用第 5 章表格：速度误差、连接/响应时延、8m 成功率、切换耗时、续航。
18. **组内分工？**
    本人负责提词器硬件、固件、脚本管理；手机端使用通用串口助手；与组员共用通信协议。
19. **最大的困难？**
    有限 RAM 下的平滑滚动（硬件滚动 + 重叠区）、W25Q64 擦写与蓝牙长文本完整性、GB2312 编码转换。
20. **下一步能做什么？**
    SD 卡在线更新字库、二级菜单与 24 点阵实物化、语音跟随滚动、多机同步。
