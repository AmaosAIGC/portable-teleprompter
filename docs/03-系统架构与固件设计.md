# 系统架构与固件设计（STM32F103C8T6）

> 🚧 **项目进行中** — 本文件随开发实时更新，预计 **2 个月内**完成作品。

## 硬件资源分配

| 功能 | 引脚 | 说明 |
|---|---|---|
| 屏 SCK | PA5 | SPI1_SCK |
| 屏 MOSI | PA7 | SPI1_MOSI |
| 屏 MISO | PA6 | ST7789 不回读，可悬空 |
| 屏 CS | PA4 | GPIO 推挽 |
| 屏 DC/RS | PB0 | 命令/数据选择 |
| 屏 RST | PB1 | 复位 |
| 背光 BL | PB5 | TIM3_CH2 PWM 调光 |
| W25Q64 CS | PA3 | 与屏共享 SPI1 |
| W25Q64 SCK/MOSI/MISO | PA5/PA7/PA6 | 共用总线 |
| HC-05 TX→MCU RX | PA10 | USART1_RX |
| HC-05 RX←MCU TX | PA9 | USART1_TX（与调试串口冲突，调试走 SWD） |
| EC11 A | PA0 | EXTI0 双边沿 |
| EC11 B | PA1 | EXTI1 双边沿 |
| EC11 按压 | PB10 | 上拉输入 |
| 按键 1/2 | PB11 / PB12 | 上拉输入，10ms 消抖 |
| 电池电压检测 | PA2 | ADC1_IN2（可选，分压 1/2） |

**SPI1 配置**：PCLK2 = 72MHz，预分频 /4 = **18MHz**（数据手册上限）。若改任务书为 36MHz 则用 /2，但属超规格运行。

## W25Q64 分区（8MB）
| 区域 | 地址范围 | 用途 |
|---|---|---|
| 字库区 | 0x000000 – 0x0FFFFF (1MB) | GB2312 16×16(≈211KB) + 24×24(≈476KB) |
| 脚本区 | 0x100000 – 0x4FFFFF (4MB) | 每份脚本预留 4 个 4KB 扇区，≥3 份，可扩到 10 份 |
| 参数区 | 0x500000 – 0x501FFF | 双区轮换（A/B）存设置与脚本索引，防写坏 |

**写入纪律**：Flash 必须先擦 4KB 扇区再写；每份脚本带 12 字节头（魔数 `0x50 0x54`、长度、CRC32、版本）。掉电时写标志位，上电校验 CRC 失败则回退到备用区。

## 渲染策略（关键，SRAM 只有 20KB）
- **不做整屏缓冲**（240×320×2 = 150KB，不可能）。
- 文本行渲染到 **一行的条带缓冲**（240×24×2 = 11.5KB 最大，或用 8 行 = 3.8KB）。
- 滚动优先用 **ST7789 硬件垂直滚动**：`VSCRDEF (0x33)` 设置滚动区，`VSCRSADD (0x37)` 改起始行，CPU 只改寄存器，不重绘。
- 当滚动到页尾（距末尾 <15 行）时，重绘下一页并复位 offset，用重叠区遮住跳变。
- 镜像：`MADCTL (0x36)` 的 MX 位，硬件级零开销。

## 滚动引擎
- 主循环 + 1ms SysTick 计数；滚动步长 = speed(px/s) × Δt。
- 速度范围 10~300 px/s，编码器每格 ±5 px/s，显示值做 EMA 滤波。
- 暂停保存 offset，恢复时从同一 offset 继续（不重绘，只停 VSCRSADD 更新）。

## GB2312 寻址
```
区位 = (区码-1)*94 + (位码-1)
地址 = FONT_BASE + 区位 * 单字字节数
16×16: 32 B/字    24×24: 72 B/字
```
UTF-8/GBK 输入统一转成 GB 内码后查表；非 GB2312 字符显示占位符，不能崩。

## 通信协议（HC-05，115200 8N1）
帧格式：`AA 55 | LEN | CMD | DATA... | CRC8`
| CMD | 功能 | DATA |
|---|---|---|
| 0x01 | 播放 | — |
| 0x02 | 暂停 | — |
| 0x03 | 下一页 | — |
| 0x04 | 上一页 | — |
| 0x05 | 跳转 | 2B 行号 |
| 0x06 | 设速度 | 2B px/s |
| 0x07 | 设行距 | 1B 档位 |
| 0x10 | 脚本开始 | 1B 序号 + 4B 长度 |
| 0x11 | 脚本数据 | 分片 ≤64B |
| 0x12 | 脚本结束 | 4B CRC32 |
| 0x20 | 查询状态 | — |

接收用 **IDLE 中断 + DMA**，避免长脚本粘包/溢出。

## 主循环状态机
`IDLE → RUNNING ⇄ PAUSED`，`MENU` 覆盖层（一级菜单：速度 / 行距 / 脚本 / 镜像）。
