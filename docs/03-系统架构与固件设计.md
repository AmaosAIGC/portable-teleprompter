# 系统架构与固件设计

## 分层
```
┌──────────── 应用层 ────────────┐
│ 状态机：IDLE / RUNNING / PAUSED │
│ 脚本管理  |  设置管理  |  遥控/蓝牙命令分发 │
├──────────── 服务层 ────────────┤
│ 滚动引擎  |  渲染引擎  |  文本模型  |  协议解析 │
├──────────── 驱动层 ────────────┤
│ ST7796/ILI9488 SPI  |  SD(FATFS)  |  BLE  |  nRF24L01  |  EC11/按键 │
└────────────────────────────────┘
```

## 核心数据结构
```c
typedef struct {
    char     name[32];      // 脚本名
    uint32_t size;          // 字节数
    uint32_t line_count;    // 行数（预扫描得到）
} script_meta_t;

typedef struct {
    uint16_t font_size;     // 16 / 24 / 32
    uint8_t  line_gap;      // 行距档位 1..3
    uint16_t fg_color;      // RGB565
    uint16_t bg_color;
    uint16_t speed_px_s;    // 滚动速度 px/s，10..400
    uint8_t  mirror;        // 0/1 水平镜像
} settings_t;
```

## 渲染策略（关键）
- **有 PSRAM**：双缓冲整屏 320×480×2B = 300KB/帧，DMA 整帧推送，滚动丝滑。
- **无 PSRAM**：条带渲染（每次 32–40 行），用滚动偏移量重绘边界行，避免全屏刷新。
- 中文：GB2312 16/24/32 点阵字库放 Flash 分区（或 SD 卡 mmap 读取），UTF-8/GBK → GB2312 索引转换表。
- **镜像**：ST7796/ILI9488 的 MADCTL 寄存器改 MX 位即可硬件镜像，不要用软件逐像素翻转（慢十倍）。

## 滚动引擎
- 以 px/s 为唯一速度量纲（不按行，避免字大的时候速度不一致）。
- 定时器 20–33ms 触发一次，累加 `offset += speed * dt`，用整数微米累加避免浮点误差。
- 渲染窗口 = `offset` 起始，只重绘与新进入窗口的行（脏行渲染）。
- 速度平滑：编码器每格 ±5 px/s，并对显示值做 EMA 滤波，避免跳变。
- 暂停：保留 offset，恢复时继续。

## 字库与编码（最大风险点，优先做）
1. TXT 常见三编码：UTF-8（有/无 BOM）、GBK、UTF-8 混合。需先探测编码。
2. UTF-8 → Unicode → GB2312 区位码 → 点阵偏移。
3. 非 GB2312 字符（生僻字、emoji）用占位符，不能崩。
4. 字库可自制：`ts3`/`font2c` 生成 bin，或直接用现成 GB2312 16/24 点阵 bin。

## 任务划分（FreeRTOS，可选）
- `task_render`：优先级高，20ms 周期
- `task_input`：编码器/按键扫描 + 消抖（20ms 采样，3 次确认）
- `task_ble` / `task_radio`：收命令，投递到队列
- `task_storage`：SD 读写，避免阻塞渲染

## 分级实现顺序（先能跑，再优化）
1. 点亮屏 + 显示英文字符串
2. 显示中文（单行）→ 多行 → 分页
3. 滚动（固定速度）→ 编码器调速 → 平滑
4. 镜像 + 装分光镜验证
5. BLE 命令 → 小程序
6. 遥控
7. 多脚本 + 手机端读回/修改
8. 掉电保存（NVS）
