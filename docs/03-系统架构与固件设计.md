# 系统架构与固件设计（STM32F401CCU6）

> 🚧 **项目进行中** — 本文件随开发实时更新，预计 **2 个月内**完成作品。

## 硬件资源分配

| 功能 | 引脚 | 说明 |
|---|---|---|
| 屏 SCK | PA5 | SPI1_SCK |
| 屏 MOSI | PA7 | SPI1_MOSI |
| 屏 MISO | PA6 | ST7789 不回读，可悬空 |
| 屏 CS | PA4 | GPIO 推挽 |
| 屏 DC/RS | PB0 | 命令/数据选择 |
| 屏 RST | PB1 | 复位 |
| 背光 BL | PB5 | TIM3_CH2 PWM 调光 |
| W25Q64 CS | PA3 | 与屏共享 SPI1 |
| W25Q64 SCK/MOSI/MISO | PA5/PA7/PA6 | 共用总线 |
| HC-05 TX→MCU RX | PA10 | USART1_RX |
| HC-05 RX←MCU TX | PA9 | USART1_TX（调试走 SWD） |
| EC11 A | PB12 | EXTI，双边沿 |
| EC11 B | PB13 | EXTI，双边沿 |
| EC11 按压 | PB14 | 上拉输入 |
| 按键 1 / 2 | PB15 / PA8 | 上拉输入，10ms 消抖 |
| 电池电压检测 | PA1 | ADC1_IN1，外接 1/2 分压（可选） |

**刻意避开 PA0**：Black Pill 板载 KEY 按键就在 PA0，占用它会被板载按键干扰产生假脉冲；PC13 是板载 LED，也不用于信号。

**SPI1 配置**：APB2 = 84MHz，预分频 /2 = **42MHz**（满足任务书 40MHz），CPOL=0/CPHA=0，MSB first，DMA 发送。

## 内存预算（64KB SRAM，足够但要规划）
| 用途 | 大小 |
|---|---|
| 行条带缓冲（240×8×2） | 3.8 KB |
| 脚本接收缓冲（DMA + 环形队列） | 8 KB |
| 帧解析 / 菜单 / 状态 | 2 KB |
| 字模缓存（每行 40 字 × 72B） | 2.9 KB |
| 栈 + 堆 | 8 KB |
| 余量 | ~40 KB |

## W25Q64 分区（8MB）
| 区域 | 地址范围 | 用途 |
|---|---|---|
| 字库区 | 0x000000 – 0x0FFFFF (1MB) | GB2312 16×16(≈211KB) + 24×24(≈476KB) |
| 脚本区 | 0x100000 – 0x4FFFFF (4MB) | 每份脚本预留 4 个 4KB 扇区，≥3 份，可扩到 10 份 |
| 参数区 | 0x500000 – 0x501FFF | 双区轮换（A/B）存设置与脚本索引 |

**写入纪律**：先擦 4KB 扇区再写；每份脚本带 12 字节头（魔数 `0x50 0x54`、长度、CRC32、版本）；参数双区轮换，CRC 校验失败自动回退。

## 渲染策略
- 不做整屏缓冲；文本渲染到 8 行条带缓冲（3.8KB）。
- 滚动用 ST7789 硬件垂直滚动：`VSCRDEF (0x33)` 定义滚动区，`VSCRSADD (0x37)` 改起始行，CPU 只写寄存器。
- 页尾剩 <15 行时重绘下一页并复位 offset，用重叠区遮住跳变。
- 镜像：`MADCTL (0x36)` 的 MX 位，硬件零开销。

## 滚动引擎
- SysTick 1ms 时基；步长 = speed(px/s) × Δt。
- 速度 10~300 px/s，编码器每格 ±5 px/s，显示值 EMA 滤波。
- 暂停保存 offset，恢复时只恢复 VSCRSADD 更新。

## GB2312 寻址
```
区位 = (区码-1)*94 + (位码-1)
地址 = FONT_BASE + 区位 * 单字字节数   // 16×16:32B  24×24:72B
```

## 通信协议（HC-05，115200 8N1）
`AA 55 | LEN | CMD | DATA... | CRC8`（详见 `04-蓝牙串口通信协议.md`）

## 主循环状态机
`IDLE → RUNNING ⇄ PAUSED`，`MENU` 覆盖层（一级菜单：速度 / 行距 / 脚本 / 镜像）。
