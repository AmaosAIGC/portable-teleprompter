# 硬件选型与 BOM

> 🚧 **项目进行中** — 本文件随开发实时更新，预计 **2 个月内**完成作品。

## 选型结论（已定）
**STM32F401CCU6（Black Pill）+ 2.8" ST7789 + W25Q64 + HC-05 + EC11**

选它的理由：F401 的 SPI1 可达 **42MHz**，满足任务书 40MHz 要求；256KB Flash / 64KB SRAM 比 F103 宽裕一倍以上；核心板约 ¥25，只比 F103 贵 ¥13，但省掉了「指标改口径」的麻烦。

## 两个关键参数

1. **SPI1 = 42MHz**：APB2 84MHz ÷ 2 = 42MHz，满足任务书 40MHz（按 42MHz 配置，实际时钟取整，论文写「配置为 42MHz，满足 40MHz 要求」）。整屏 150KB ÷ 5.25MB/s ≈ **28.6ms**，远优于 200ms 级要求。
2. **SRAM 64KB**：整屏缓冲 150KB 仍不够，继续用 ST7789 硬件垂直滚动（VSCRDEF 0x33 / VSCRSADD 0x37）+ 行条带渲染；但 64KB 允许做 4~8 行的多行缓冲与双缓冲切换，滚动比 F103 更从容。

## 下单注意
1. 屏必须 **ST7789**（不是 ILI9341），否则初始化参数全变。
2. 核心板认准 **F401CCU6**（不是 F411/F103），Flash 256KB、SRAM 64KB。
3. W25Q64 选 SPI 接口、3.3V 电平模块。
4. HC-05 买**主从一体**，可用 AT 指令改波特率到 115200。
5. 一次下单省运费。
