# 硬件选型与 BOM

> 🚧 **项目进行中** — 本文件随开发实时更新，预计 **2 个月内**完成作品。

## 选型结论（已定）
**STM32F103C8T6 + 2.8" ST7789 + W25Q64 + HC-05 + EC11**

选它的理由：最便宜、资料最多、64KB Flash 够放程序（字库存外部 W25Q64）、20KB SRAM 配合 ST7789 硬件滚动够用。

## 必须知道的两个硬约束

1. **SPI 上限 18MHz**（F103 数据手册）。任务书原写 40MHz 达不到——要么把任务书改成 18MHz（推荐，零成本），要么换 F401（+¥13）。文本滚动不需要更高带宽：整屏 150KB ÷ 2.25MB/s ≈ 66ms。
2. **SRAM 只有 20KB**，整屏缓冲需 150KB，绝不可能。方案是 ST7789 的硬件垂直滚动（VSCRDEF 0x33 / VSCRSADD 0x37）+ 条带渲染。

## 下单注意
1. 屏一定选 **ST7789** 驱动（不是 ILI9341），否则初始化参数全变。
2. W25Q64 要 SPI 接口模块，最好带 3.3V 电平。
3. HC-05 买**主从一体**，默认波特率 9600/38400 可 AT 改到 115200。
4. 一次下单，省运费。
