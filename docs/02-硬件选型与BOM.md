# 硬件选型与 BOM

> 🚧 **项目进行中** — 本文件随开发实时更新，预计 **2 个月内**完成作品。

## 选型结论（已定，不再比较）
**ESP32-S3 一体带屏开发板 + MicroSD + nRF24L01 + EC11 + 微信小程序 BLE**

选 ESP32 而非 STM32 的理由：
1. BLE 内置，省一个蓝牙模块和一半调试时间
2. PSRAM 可上 8MB，中文双缓冲不吃紧
3. SPI 屏、SD、FATFS 资料最多
4. 手机端对接成本低

## 选型红线（下单前逐条核对）
1. **必须 ESP32-S3，带 PSRAM**（≥2MB，最好 8MB）。普通 ESP32 + 4MB Flash 无 PSRAM 的板子刷中文全屏会闪。
2. **剩余可引出 IO ≥7 个**：EC11(2–3) + 按键(2) + nRF24L01 CE/CSN(2) + 中断(1)。
3. **带 TF 卡座**（省掉独立 SD 模块和接线）。
4. 屏 ≥2.8 寸，优先 IPS（比 TFT 亮度高、视角大），分辨率 ≥320×240；3.5 寸 480×320 更舒适。
5. 手机端必须 BLE（经典蓝牙 SPP 不支持 iOS）。

## 下单注意事项
1. 除结构和外壳外**一次下单**，省运费。
2. 模块优先选**已焊排针**规格。
3. 外壳、亚克力等电路调通、尺寸量准后再买。
4. 提前两周下单，留出返修/补货缓冲（这是进度保险）。
